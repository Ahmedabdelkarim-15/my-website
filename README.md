## ✏️ كيف تُعدّل المنتجات

كل المنتجات موجودة في ملف واحد فقط: **`js/products.js`**

### تغيير اسم أو سعر منتج:
1. افتح ملف `js/products.js` بأي محرر نصوص (حتى Notepad العادي).
2. ابحث عن اسم المنتج اللي عايز تعدّله.
3. غيّر القيمة اللي جنب `name` لتغيير الاسم.
4. غيّر الرقم جنب `price` لتغيير السعر.
5. احفظ الملف وارفعه تاني على الاستضافة.

### مثال عملي:
```
قبل التعديل:
  name: "تيشيرت قطن رجالي كلاسيك",
  price: 199,

بعد التعديل:
  name: "تيشيرت قطن رجالي سادة",
  price: 220,
```

### تغيير صورة منتج:
1. ارفع الصورة الجديدة على أي موقع استضافة صور مجاني (مثل [Imgur](https://imgur.com)).
2. انسخ رابط الصورة.
3. ضع الرابط جنب `image` في ملف `js/products.js`.

### إضافة منتج جديد:
انسخ أي منتج (من `{` لغاية `},`) والصقه في نفس القسم، وعدّل بياناته. تأكد إن رقم `id` مختلف عن أي منتج تاني.

### حذف منتج:
احذف كل شيء من `{` لحد `},` الخاصة بالمنتج.

## ☁️ الطريقة الأولى: Cloudflare Pages (مُستحسن)

**مجاني بالكامل — استضافة بلا حدود زيارات — شهادة HTTPS تلقائية**

1. ادخل على [Cloudflare Pages](https://pages.cloudflare.com) وسجّل حساب مجاني.
2. اضغط على **"Create a project"**.
3. اختر **"Direct Upload"** (رفع مباشر).
4. اسحب مجلد المتجر بالكامل وأفلته في الصفحة.
5. سمّي المشروع مثلاً: `market-eg`
6. اضغط **Deploy** واستنى دقيقة.
7. ✅ هيظهر لك رابط المتجر: `market-eg.pages.dev`

### لتحديث المتجر بعد أي تعديل:
- ادخل على Dashboard → المشروع → اضغط **"Create new deployment"** → ارفع المجلد المُحدّث.

## 🌐 الطريقة الثانية: Netlify (سحب وإفلات)

**مجاني — أسرع طريقة حرفياً**

1. ادخل على [Netlify Drop](https://app.netlify.com/drop).
2. اسحب مجلد المتجر بالكامل وأفلته في المنطقة المحددة.
3. ✅ خلال ثواني هيظهر لك الرابط: `market-eg.netlify.app`

### لتغيير اسم الرابط:
- Site settings → Change site name → اكتب `market-eg` → Save.

## 🔥 الطريقة الثالثة: Firebase Hosting

1. ادخل على [Firebase Console](https://console.firebase.google.com).
2. أنشئ مشروع جديد باسم `market-eg`.
3. اختر **Hosting** من القائمة.
4. ثبّت أدوات Firebase على جهازك (محتاج Node.js):
   ```
   npm install -g firebase-tools
   firebase login
   firebase init hosting
   ```
5. اختر مجلد المتجر كمجلد عام.
6. انشر:
   ```
   firebase deploy
   ```
7. ✅ هيظهر لك رابط: `market-eg.web.app`

## 🔒 قائمة الأمان اليومية

✅ **افعل هذه الخطوات لحماية متجرك:**

| الخطوة | التفاصيل |
|--------|----------|
| 🔑 فعّل المصادقة الثنائية (2FA) | على حساب Gmail وحساب الاستضافة (Cloudflare/Netlify/Firebase) |
| 💾 نسخة احتياطية | بعد كل تعديل، ارفع نسخة من مجلد المتجر على Google Drive |
| 🔄 راجع الطلبات | تابع رسائل واتساب يومياً لاستلام الطلبات الجديدة |
| 🚫 لا تشارك بيانات الدخول | لا تعطي كلمة سر حساب الاستضافة لأي شخص |
| 🔍 تأكد من HTTPS | تأكد إن رابط متجرك يبدأ بـ `https://` (القفل الأخضر) |
