# 🛒 market.com — المتجر الإلكتروني الشامل الفاخر

> **متجر إلكتروني متكامل وعصري للملابس، المنتجات الغذائية، والأدوات المنزلية**  
> مصمم وفق أعلى معايير الـ UX/UI العالمية مع دعم وسائل دفع متعددة وتوصيل سريع للقاهرة والجيزة.

---

## ✨ المميزات الجديدة والتحديثات الشاملة

### 💳 1. منظومة دفع متكاملة (Multi-Payment System):
- **💵 الدفع عند الاستلام (كاش)**: خيار المعاينة والدفع نقداً عند باب المنزل.
- **📱 المحافظ الإلكترونية المصرية**: فودافون كاش، أورنج كاش، اتصالات كاش، و WE Pay (مع أزرار نسخ فورية وحقل تأكيد رقم المحول).
- **🏦 إنستاباي والحسابات البنكية المصرية**: دعم الدفع الفوري عبر InstaPay (معرّف IPA) وحساب البنك الأهلي المصري مع نسخ الـ IBAN بضغطة زر واحدة.
- **💳 البطاقات البنكية والائتمانية**: فيزا، ماستركارد، وبطاقة ميزة الوطنية المصرية مع توليد رابط دفع إلكتروني مشفر وآمن.

### 💖 2. نظام قائمة المفضلة (Wishlist System):
- حفظ المنتجات المفضلة بنقرة واحدة عبر أيقونة القلب على كل بطاقة منتج.
- شارة حية لعدد المنتجات في المفضلة بالهيدر العلوي.
- درج جانبي منزلق لاستعراض المفضلة وإمكانية نقل المنتجات مباشرة إلى السلة أو تفريغها.
- حفظ تلقائي للمفضلة في المتصفح عبر `localStorage`.

### 🎧 3. مركز الدعم الفني والتواصل (Support & Contact Hub):
- درج جانبي متكامل للدعم الفني وخدمة العملاء.
- زر تواصل مباشر عبر واتساب، وزر اتصال هاتفي فوري.
- قسم الأسئلة الشائعة التفاعلي (FAQ Accordion) حول مواعيد الشحن وسياسة الاستبدال والاسترجاع وطرق الدفع.
- زر عائم (Floating Action Button) للوصول السريع لخدمة العملاء.

### 🎨 4. أيقونات وتصميم عصري عالمي:
- استبدال الإيموجيز القديمة بحزمة متجهات **Font Awesome 6** الحديثة فائقة النقاء.
- تأثيرات زجاجية راقية (Glassmorphism) مع هيدر ضبابي شفاف وظلال ناعمة تفاعلية.
- تقييمات نجوم ذهبية وعدد مراجعات لكل منتج.

### 🌈 5. خلفيات بصرية مخصصة لكل قسم (Dynamic Theming):
- **قسم الملابس**: تدرجات أزياء راقية وألوان دافئة مريحة للعين.
- **قسم المنتجات الغذائية**: لمسات خضراء زمردية تعبر عن النقاء والطزاجة.
- **قسم الأدوات المنزلية**: أجواء ديكورية دافئة مستوحاة من المنازل العصرية.
- **قسم عروض اليوم**: تدرجات حيوية خاصة بالتخفيضات.

## 📁 هيكل ملفات المشروع

```
website/
├── index.html          ← الصفحة الرئيسية (الهيكل، الأدراج، خيارات الدفع)
├── css/
│   └── styles.css      ← التصميم العالمي، الثيمات، والألوان المتجاوبة
├── js/
│   ├── products.js     ← بيانات المنتجات، الأسعار، التقييمات، والشارات
│   └── app.js          ← منطق السلة، المفضلة، الدفع المتعدد، والواتساب
├── _headers            ← إعدادات الأمان السحابية وسياسة CSP المحدثة
└── README.md           ← هذا الدليل التوثيقي
```

## ✏️ تعديل المنتجات وإضافة أصناف جديدة
لتعديل أي منتج أو تغيير سعره، افتح ملف `js/products.js` وقم بتعديل القيم بسهولة تامة:
- `name`: اسم المنتج
- `price`: السعر الحالي بالجنيه
- `oldPrice`: السعر قبل الخصم (إن وجد)
- `image`: رابط صورة المنتج عالية الدقة
- `badge`: الشارة الظاهرة على المنتج (مثل: "خصم 20%" أو "الأكثر مبيعاً")
